# Demo and Acceptance Plan

## Controlled demo
Show normal, ambiguous and probable events. Demonstrate evidence, manual plate review, officer decision, history and export.

## Live final-round demo
1. Start webcam
2. Set clean baseline
3. Start monitoring
4. Teammate deposits a clean box
5. Wait for stable scene
6. Detect scene change
7. Generate evidence
8. Request cleanup

Use a recorded vehicle clip separately for tracking/ANPR. Maintain a recorded fallback for every live step.

## Demo honesty
State what is working, what is demo-stage and what needs pilot permission. Never use a fixed label that implies real detection.

## Release acceptance checklist
- Clean installation/run instructions
- No placeholders or private data
- Normal and failure paths tested
- Evidence/decisions persist
- Export opens correctly
- Status labels accurate
- Known limitations documented
- Backup demo available
